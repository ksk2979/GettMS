# Gett Core

Gett Server용 경제·NPC 상점 모드입니다 (NeoForge 1.21.1).

- 골드 경제: 잔액 조회·지급·차감·설정, 잔액 순위, 수표 발행/사용
- NPC 상점: 구매·판매·전체판매, 상점 편집 모드
- NPC 대화 데이터 연동, 경험치 구슬, 귀환석과 귀환 지점
- NPC 퀘스트: 메인 + 서브퀘스트, 보상 고르기, 함께 잡기, 퀘스트 목록 HUD

## 빌드

```
./gradlew build
```

결과물은 `build/libs/` 아래에 생성됩니다.

## 설정 파일

서버 실행 후 `config/gettcore/` 폴더에 상점, 대화, NPC 매핑, 경제 설정 JSON 파일이 위치합니다.
파일을 수정한 뒤 `/gett reload`로 다시 적용할 수 있습니다.

## 명령어

한글 명령과 영문 별칭이 같이 등록되어 있습니다. `<...>` 는 필수, `[...]` 는 선택 인수입니다. 관리자 명령은 OP 2 이상 또는 해당 권한 노드가 필요합니다.

### 일반

| 명령어 | 설명 |
| --- | --- |
| `/돈` (`/money`) | 내 잔액 확인 |
| `/돈 순위` | 골드 순위 |
| `/수표발행 <금액>` (`/check`) | 금액이 적힌 수표 아이템 발행(잔액에서 차감) |
| `/몹정보` (`/mobinfo`) | 바라보는 몹의 종·체력·포획틀 등급별 포획 확률 표시 |

### 관리자

| 명령어 | 설명 |
| --- | --- |
| `/gett reload` | `config/gettcore/` 설정 파일 다시 읽기(상점·대화·NPC·마법부여·펫·보스지점·보호구역·강화) |
| `/gett 편집` (`/gett editor`) | 웹 편집기 열기(주소를 채팅에 표시) |
| `/귀환지점 설정` (`/returnpoint set`) | 현재 위치를 귀환석 귀환 지점으로 설정 |
| `/돈 지급\|차감\|설정 <플레이어> <금액>` | 골드 지급·차감·설정 |
| `/돈 조회 <플레이어>` | 다른 플레이어 잔액 확인 |
| `/펫 주기 <플레이어> <야생 종 id> [변종]` (`/pet give`) | 펫 도감에 종 추가 (예: `naturalist:lion`) |
| `/펫 삭제 <플레이어> <번호>` (`/pet remove`) | 도감에서 번호(`/펫 목록` 순서)의 펫 삭제 |
| `/펫 목록 <플레이어>` (`/pet list`) | 플레이어의 펫 도감 보기 |
| `/보스지점 추가 <id> <보스 종>` (`/bosspoint add`) | 현재 위치를 보스 스폰 지점으로 등록 |
| `/보스지점 삭제\|이동\|리셋 <id>` | 지점 삭제·이동·현재 보스 제거 후 재스폰 |
| `/보스지점 목록` | 지점 목록과 상태 |
| `/보스지점 모션 [람각]` (`/bosspoint anim [ramgak]`) | 디버그: 32칸 안 가장 가까운 보스 기린에게 내려찍기 앞다리 모션 재생 (`람각`/`ramgak`을 붙이면 람각 발차기 모션) |
| `/보호구역 추가 <id>` (`/region add`) | WorldEdit 선택 영역(위아래 10칸 확장)을 보호구역으로 등록 |
| `/보호구역 삭제\|이동 <id>` | 구역 삭제·구역 중심으로 이동 |
| `/보호구역 목록`, `/보호구역 정보` | 구역 목록 / 지금 서 있는 곳의 구역 |
| `/강화 <단계>` (`/reinforce`) | 손에 든 장비의 강화 단계를 그 값으로 설정(0 = 해제). 설정의 최대 단계보다 높게도 가능 |
| `/인벤 <플레이어>` (`/invsee`) | 접속 중인 플레이어의 인벤토리(가방·핫바·갑옷·보조손) 열기. 넣고 빼기 가능, 회색 유리판 칸은 빈 자리 |
| `/엔더 <플레이어>` (`/endersee`) | 접속 중인 플레이어의 엔더 상자 열기(넣고 빼기 가능) |
| `/관전` (`/spectate`) | 관리자 관전 모드 켜기/끄기. 켜면 지형을 뚫고 날아다니고 다른 플레이어에게 안 보임(Tab 목록·접속/퇴장 메시지 포함, 재접속해도 유지). 관전 중인 관리자끼리는 머리만 보임. 끄면 원래 게임 모드로 그 자리에 나타남 |
| `/퀘스트 초기화 <플레이어> [라인]` (`/quest reset`) | 라인 생략 시 모든 줄(메인+서브)의 진행·완료 기록 삭제, 지정하면 그 줄만. 받은 보상은 회수 안 됨 |
| `/퀘스트 완료 <플레이어> [라인]` (`/quest complete`) | 그 줄(생략 시 메인)의 현재 퀘스트를 보상 포함해 완료 |
| `/퀘스트 이동 <플레이어> <퀘스트> [라인]` (`/quest goto`) | 그 줄(생략 시 메인)에서 그 퀘스트 앞을 모두 완료 처리(보상 없음) |

권한 노드: `gettcore.admin`(reload·편집기·귀환지점·인벤·엔더·관전), `gettcore.economy.admin`, `gettcore.economy.check`, `gettcore.shop.edit`, `gettcore.boss.admin`, `gettcore.protect.admin`.

### 인챈트(마법부여) 넣기

특수 능력은 진짜 인챈트로 등록되어 있어서 바닐라 `/enchant` 명령으로 바로 넣을 수 있습니다(OP 전용).

```
/enchant @s gettcore:harvest 3        # 들고 있는 괭이에 수확 III
/enchant <플레이어> gettcore:leech 2  # 그 플레이어가 든 검에 흡혈 II
/enchant @s minecraft:sharpness 5     # 바닐라 인챈트도 같은 방식
```

- 도구당 특수 능력은 하나입니다. 이미 다른 특수 능력이 있으면 `/enchant` 가 거부되므로, 먼저 숫돌로 지우거나 마법부여사에게 다시 돌리세요.
- 레벨은 아래 최대 레벨까지만 들어갑니다.

| 도구 | 능력 id (최대 레벨) |
| --- | --- |
| 괭이 | `harvest` 수확(3), `replant` 재심기(1), `bounty` 풍작(3) |
| 곡괭이 | `vein` 광맥(3), `area` 광역(1), `smelt` 제련(1) |
| 도끼 | `timber` 벌목(3), `resapling` 벌목 재심기(1), `lumber` 목재 보너스(3) |
| 검 | `sweep` 연격(3), `leech` 흡혈(3), `wisdom` 경험(3), `execute` 처형(3), `plunder` 전리품(3) |
| 활 | `volley` 다발(1), `quickdraw` 속사(3), `homing` 추적(1) |
| 낚싯대 | `lure` 손맛(3), `bigcatch` 대어(3), `treasure` 월척(3) |

아이템을 바로 주려면 `/give @s gettcore:enchant_stone 16` (마법부여석), `/give @s gettcore:reinforce_stone 64` (강화석), `/give @s gettcore:capture_ball_gold` (금 포획틀) 처럼 씁니다.

### 강화·마법부여 비용 (1.5.0~)

- 강화석·마법부여석은 칸에 넣지 않고 **인벤토리(핫바·왼손 포함)에서 자동으로** 셉니다. 화면에 `강화석 x필요 (보유 N)`, `골드 (보유 N)` 이 표시되고 모자라면 빨간색입니다.
- 강화 = 강화석 + 골드(단계별 `goldCost`), 마법부여 = 마법부여석 1개 + 골드(`enchantGoldCost`). **실패해도 둘 다 소모**됩니다.
- 수치는 웹 편집기 '강화' 탭(단계별 표의 골드 열, 겉날개 카드, 마법부여 비용 카드) 또는 `reinforce.json` 에서 바꿉니다.

### 겉날개

- **Elytra Slot** 모드(+ Caelus API)로 Curios **등 칸**에 겉날개를 낄 수 있습니다(배낭과 같은 칸 — 둘 중 하나). 흉갑과 함께 날 수 있습니다.
- 대장장이 강화 대상: 1강 = 내구도 무한(1강 비용만 따로: 기본 강화석 32 + 50,000 골드), 2강부터 단계당 비행 속도 +2%(30강 +58%), 15강 이상 폭죽 부스트 +50%. 흉갑 칸·등 칸 어디에 껴도 적용됩니다.

### 퀘스트 (1.6.0~)

- **서브퀘스트**: 메인과 별개의 서브 줄을 동시에 진행합니다. 웹 편집기 퀘스트 탭에서 줄마다 퀘스트를 주는 NPC와 시작 조건(requires)을 정합니다. 한 NPC가 여러 퀘스트를 줄 수 있으면 대화에 선택지가 나옵니다.
- **보상 고르기**: 고르는 보상으로 설정하면 보고 화면에서 하나를 골라 받습니다.
- **몬스터 아무거나**: 처치 목표를 `@monster` 로 두면 모든 몬스터가 인정됩니다.
- **함께 잡기**: 처치 전 30초 안에 때린 모든 플레이어가 처치로 인정되며, 펫이 때린 것은 주인에게 갑니다.
- **HUD**: 메인 퀘스트는 위에 고정, 서브 줄은 아래 목록. 채팅창을 연 상태에서 마우스 휠로 서브 목록을 스크롤합니다. `Ctrl + -` 로 위치와 높이(6~30줄, 기본 12)를 조정합니다.
- **J 화면**: 줄 목록이 나오고 ◉/○ 로 줄별 HUD 표시를 켜고 끕니다.

### 상점 탭

탭이 7개를 넘으면 탭 줄 양끝에 ◁/▷ 가 나타나 넘겨 볼 수 있습니다. 아이템 행(아이콘·이름 쪽)에 마우스를 올리면 아이템 툴팁이 나옵니다.

### 필드 몬스터 골드 (1.7.0~)

필드에서 자연스럽게 나온 몬스터를 잡으면 막타를 친 플레이어(펫이 잡으면 주인)가 골드를 받습니다(액션바에 `+N 골드`). `config/gettcore/field_gold.json`:

- 금액 = 최대 체력 × `healthRate` + 공격력 × `attackRate` + 방어력 × `armorRate`, 반올림 후 `min`~`max` 안으로 (기본 0.5 / 1 / 1, 최소 10, 최대 1000). 좀비 ≈ 15, 거미 10.
- `overrides`: 몹별 고정 금액(`"minecraft:enderman": 40`). 0 이면 그 몹은 안 줌. `enabled: false` 면 전체 끔.
- 안 주는 경우: 사냥터 몹(사냥터 보상이 따로), 보스, 스포너·시련 스포너·알·명령어·버킷·디스펜서·번식·다른 몹이 소환한 몹. `/gett reload` 로 바로 적용.

### 보스 스킬 (1.9.0~)

`config/gettcore/bosses.json` 에서 보스 종류별로 선공/후공(`aggro`), 탐지·해제 거리, 격앙(체력 비율) 설정과 스킬 목록(`skills`)을 정합니다. 웹 편집기(`/gett 편집`)의 '보스·스킬' 탭에서 보스 개체와 사냥터 개체의 스킬을 편집할 수 있고 `/gett reload` 로 바로 적용됩니다.

- 스킬 종류: `stomp` 내려찍기(앞다리 모션 + 지형 파괴), `wind_line` 람각(직선 바람 + 뒤따르는 여진). 외침(`shout`)이 켜진 스킬은 발동 시 스킬 이름이 근처 플레이어에게만 외침으로 표시됩니다(기본값: 람각은 켜짐, 내려찍기는 꺼짐).
- 스킬 피해는 몹 공격으로 들어가므로 플레이어가 받는 피해는 월드 난이도에 따라 달라집니다(편집기의 '피해'는 보통 난이도 기준 값입니다).
- 보스 기린(`gettcore:boss_giraffe`)이 추가되었고, 보스 7종 소환 알은 크리에이티브 인벤토리의 'Gett' 탭에 있습니다(테스트용).
- 사냥터 개체도 스킬을 가질 수 있으며, 야생 몹(사냥터 태그 없음)은 스킬을 쓰지 않습니다.
